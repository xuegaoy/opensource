## 一、为什么要有这个本子

输入（看讲解）只能「眼熟」，输出（主动回忆）才能「记住」。本子里所有题目都来自你已经有的材料：

| 来源 | 出什么东西 |
|---|---|
| `分析/01_高频语法50.md` + `_data/frozen/grammar50.json` | 每天 2 条语法：默写接续＋意思，再写一道该语法的**原题 4 选 1**（45/50 条找回了原题） |
| `分析/02_高频词汇500.md` + `_data/frozen/vocab500.json` | 每天 20 词：看汉字写假名／看假名写汉字／看中文写词（499/500 词找回了原题） |
| `分析/05_2021-2024高频词汇200_语法30.md` | 每天 5 个近卷考点词 + 3 个辨析组选项词 + 1 条近卷语法 |
| `分析/04_2026年12月押题_100词30语法.md` | Day18–25 每天附 A 档速测（44 词，不计分，考前必须全会） |
| `_data/exams/*.json`（21 套旧卷）+ `exams_recent/`（3 套近卷）+ `build_recent.py`（2 套转录） | 每天 6 道真题实战：当天学的词/语法**当年是怎么考的** |

| 部分 | 题量 | 分值 | 训练的能力 |

| 一、词汇输出 | 20 | 40 | 主动回忆（写假名/写汉字/写词） |
| 二、语法输出 | 2 条 | 12 | 接续默写 + 真题选择 |
| 三、近卷新词 | 5+3+1 | 15 | 近卷考点 + 辨析组 + 近卷语法 |
| 四、真题实战 | 6 | 24 | 限时做题（旧卷+近卷原题） |
| 五、隔日回炉 | 6+1~2 | 9 | 1/3/7 天间隔重复 |
| 合计 | | **100** | 约 30–40 分钟 |

## 四、规则

1. **全部写完再翻 `<details>` 答案**——先看答案等于没练。
2. 得分低于 70 分的那一天，第二天把错词在日课里重背一遍再做题。
3. 错题一律抄进 [`../202612备考/日课/错题本.md`](../202612备考/日课/错题本.md)，按 1/3/7 天回炉。
4. Day18 起（12/01）每天加 10 min 过 `04_押题` 的 A 档；题已内嵌在每天的「附」里。
5. **12/06 考试当天**：不做本练习。只看 `错题本` 里 +7 天没勾掉的题 + `04_押题` A 档 44 词。
